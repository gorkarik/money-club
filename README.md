# MONEY CLUB

Бот для арбитража между двумя биржами: **Entropy** (Hyperliquid) и
**Lighter Robinhood chain**, тикер **SNDK**. Когда одна и та же бумага на одной
бирже дороже обычного, а на другой дешевле, бот одновременно продаёт дорогую
и покупает дешёвую, держит позицию без направленного риска (дельта-нейтрально)
и закрывает её, когда разница возвращается к норме.

Управление — через меню в терминале, без ручного редактирования файлов.

## Установка

1. Арендуйте сервер с **Ubuntu 22.04 / 24.04** (лучше в Токио — там стоят
   серверы обеих бирж; хватает 1–2 ГБ памяти).
2. Зайдите на сервер по SSH и вставьте одну строку:

```bash
curl -fsSL https://raw.githubusercontent.com/gorkarik/money-club/main/install.sh | bash
```

Установка занимает 2–3 минуты и в конце сама открывает меню.
После этого меню открывается **само при каждом входе на сервер**, а также
командой `moneyclub`.

## Меню

```
  1  Старт                 боевой режим или тестовая запись без денег
  2  Стоп                  мягкая остановка, позиции остаются захеджированными
  3  Дашборд               живой экран бота; выход — клавиша Q
  4  Анализ / калибровка   статистика премии за 24 ч / 48 ч / неделю / всё время
  5  Настройки             пороги входа, лимиты, ключи
  0  Выход                 бот продолжает работать на сервере
```

Бот работает в фоне: закрытие терминала, ноутбука или обрыв интернета его
не останавливают.

### Ключи

Меню само спросит их при первом запуске (или: Настройки → Ключи):

| Ключ | Где взять |
|---|---|
| `HL_PRIVATE_KEY` | app.hyperliquid.xyz/API — приватный ключ API (agent) кошелька |
| `HL_ACCOUNT_ADDRESS` | адрес **основного** кошелька, на котором деньги (не агента) |
| `LIGHTER_ACCOUNT_INDEX` | номер аккаунта на Lighter |
| `LIGHTER_API_KEY_INDEX` | индекс API-ключа, выбранный при создании (например 4) — **не Public Key** |
| `LIGHTER_API_PRIVATE_KEY` | robinhoodchain.lighter.xyz/apikeys — Private Key |

Для тестовой записи ключи не нужны. Используйте отдельный кошелёк только под
бота.

### Настройки по умолчанию

| Параметр | Значение |
|---|---|
| Центр премии (midline) | −7.0 bps |
| Порог продажи (upper) | +4.0 bps |
| Порог покупки (lower) | −4.5 bps |
| Лимит позиции | $25 на каждой бирже |
| Одна сделка | до $20 |

Пороги получены по ~4 суткам записи рынка. Премия со временем «плывёт», поэтому
раз в неделю запускайте **Анализ / калибровку**, копируйте блок с результатом
и отправляйте Клоду (claude.ai) с вопросом, стоит ли обновить калибровку.
Там же можно сразу применить рекомендованные пороги.

## Обновление

Запустите ту же строку установки ещё раз. Код обновится, а ключи и настройки
останутся прежними. Если бот работал, после обновления сделайте Стоп → Старт.

## Файлы

| Файл | Что это |
|---|---|
| `club.py` | меню MONEY CLUB |
| `install.sh` | установка одной командой |
| `config.yaml` | ваши настройки (создаётся из `config.example.yaml`) |
| `.env` | ваши ключи — никому не пересылайте |
| `logs/` | записанные данные рынка, сделки и журнал бота |

Отключить автозапуск меню при входе: удалите блок `>>> moneyclub >>>`
в файле `~/.bashrc`.
